# GM-MCP

An MCP server that lets an LLM interrogate Grigorios (Greg) Miaritis as a job candidate: profile, work experience, projects, and full-text search over all of it.

## Tools

- `get_profile` — name, role, location, summary, links
- `list_experience` / `get_role` — work history and role detail
- `list_projects` / `get_project` — side projects and detail
- `search` — full-text search across everything
- `get_pointless_fact` — a fact about `.less`, things
