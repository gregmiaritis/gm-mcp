# GM-MCP

An MCP server that lets an LLM interrogate Grigorios (Greg) Miaritis as a job candidate: profile, work experience, projects, evidence, and full-text search over all of it.

## Tools

- `get_profile` — name, role, location, summary, links
- `list_experience` / `get_role` — work history and role detail
- `list_projects` / `get_project` — side projects and detail
- `list_evidence` / `get_evidence` — evidence backing specific claims (metrics, artifacts, links), filterable by role/project
- `search` — full-text search across experience, projects, and evidence
- `get_pointless_fact` — a fact about `.less`, things
